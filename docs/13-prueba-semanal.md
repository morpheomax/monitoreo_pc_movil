# Prueba de uso — 19 al 25 de octubre de 2026

Usar normalmente Android0.7.0 con el agente0.4.0; no necesitas reinstalar la app
para cambiar de computador. Los archivos y pasos están en README.

Durante la semana conviene observar:

- Conexión rápida USB en Windows: abrir lanzador, confirmar equipo y ver métricas.
- Desconectar/reconectar cable, reparar USB y comprobar que los datos se recuperan.
- Legibilidad horizontal, temas, gráficas ampliadas y regreso con X/Atrás.
- Una sesión de trabajo prolongada: grabar, finalizar, revisar informe/exportar CSV.
- Cierre individual únicamente sobre aplicaciones de prueba con trabajo guardado;
  comprobar resultado y protegidos. Cerrar la aplicación completa aún está pendiente.

Para cada problema o propuesta anota:

| Dato | Ejemplo de información útil |
|---|---|
| Equipo y versiones | Windows/macOS, versión de app/agente |
| Pasos | Vista abierta, botón tocado, estado del cable |
| Resultado | Qué esperabas y qué ocurrió |
| Frecuencia | Una vez, a veces o siempre; tiempo de uso previo |
| Impacto | Bloquea uso, hace perder tiempo o mejora visual |

Al volver revisaremos tus observaciones y priorizaremos correcciones y mejoras.
No compartas el token temporal en las observaciones.
